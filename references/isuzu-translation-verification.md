# Isuzu 十语言翻译页面核验

日期：2026-08-13

日语 Isuzu 品牌页实际显示 4HK1、6HK1、6UZ1、6WG1 四台发动机。标题使用“いすゞ + 型号 + ディーゼルエンジン”；车型类型、规格和详情使用日语技术表述。排量、功率、马力、扭矩、燃料和排放标准显示为“リットル、キロワット、馬力、ニュートンメートル、軽油、ユーロ”，未显示原始 `kW`、`HP`、`Nm`、`Diesel`、`Fuel Type` 或 `Emissions Standard` 标签。

两项 Isuzu 专用回归测试共 7 项通过：四台实际发动机的英文规格与详情严格对齐产品源数据，37 个实际零件的十语言列表描述与详情弹窗均不会触发 OEM 通用详情回退。

日语零件列表实际显示 37 个零件的本地化名称、分类和说明。首个“エンジンオイルフィルター”的详情弹窗已实际打开，标题、分类“メンテナンス/ろ過システム”和维护说明均为专用日语内容。
